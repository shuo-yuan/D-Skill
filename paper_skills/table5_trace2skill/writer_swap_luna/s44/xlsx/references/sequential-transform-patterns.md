# Sequential Transform Patterns\n\n## Core Principle\nWhen transforming spreadsheet data sequentially, keep source state and output state strictly separate. Never let a value you just wrote become the input for the next row's decision logic.\n\n## Excel-Style Alphabet Encoder\nUse a dedicated 1-based base-26 routine for suffix generation. Do not concatenate letters onto prior output.\n\n```python\ndef to_excel_alpha(n: int) -> str:\n    '''Convert 1-based index to Excel column letters: 1->a, 26->z, 27->aa.'''\n    result = ''\n    while n > 0:\n        n, rem = divmod(n - 1, 26)\n        result = chr(ord('a') + rem) + result\n    return result\n```\n\n## Blank-Row Fill Pattern\nWhen filling blank rows with incremented labels based on the last non-blank value:\n\n1. Read the entire column into a list (original state).\n2. Iterate through the list with a `blank_count` counter.\n3. On a non-blank cell: store it as `last_numeric_base`, reset `blank_count = 0`.\n4. On a blank cell: increment `blank_count`, generate label as `last_numeric_base + to_excel_alpha(blank_count)`.\n5. Write all generated labels in a separate pass.\n\n```python\n# Read original values first\noriginal = [ws.cell(row=r, col=c).value for r in range(start_row, end_row + 1)]\n\n# Build output from original state only\noutput = []\nlast_base = None\nblank_count = 0\n\nfor val in original:\n    if val is not None and str(val).strip() != '':\n        last_base = str(val).strip()\n        blank_count = 0\n        output.append(last_base)\n    else:\n        blank_count += 1\n        if last_base is None:\n            raise ValueError('First cell cannot be blank')\n        output.append(f'{last_base}{to_excel_alpha(blank_count)}')\n\n# Write results back\nfor i, val in enumerate(output):\n    ws.cell(row=start_row + i, col=c, value=val)\n```\n\n## Anti-Patterns to Avoid\n- **Do not** scan the worksheet for the prior nonblank after writing earlier blanks; this picks up generated labels as bases.\n- **Do not** derive the suffix index by counting already-modified cells; the count no longer reflects the original blank run.\n- **Do not** concatenate letters onto the previous output label; use the encoder on a clean counter.
