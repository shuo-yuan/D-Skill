# Formula Patterns\n\n## Non-contiguous Criteria Checks\nWhen related event types are stored in different columns, do not assume a contiguous range. Use separate conditional counts and combine them with `AND`.\n\n## Gating to the First Row of a Group\nCompare the current group key with the preceding row's key before evaluating other conditions; output only on the first row of each group.\n\n## Cumulative Expanding Ranges\nAnchor the start cell with `$` and let the end row vary with the destination row: `$A$2:A{r}`.\nExample: `=COUNTIF($A$2:A2, \"Potato\")` copied down as `=COUNTIF($A$2:A3, \"Potato\")`.\n\n## Priority with Nested Conditionals\nNest conditions in the exact order specified, testing highest priority first.\nPattern: `=IF(COUNTIF(range, \"Priority1\")>0, \"Result1\", IF(COUNTIF(range, \"Priority2\")>0, \"Result2\", \"Fallback\"))`\n\n## Programmatic Application\nIterate target rows, build row-specific formula strings, assign to target cells, and save once after all assignments.\n\n## Ranking with Ties within Groups\nUse `COUNTIFS` for strictly greater values in the same group plus a cumulative `COUNTIFS` for equals through the current row; wrap in `IF` to keep blank rows blank.\n\n## OR-list Aggregation\nUse `SUMPRODUCT` with `ISNUMBER(MATCH(data_range, criteria_list, 0))` instead of passing a range directly to `SUMIFS`.\n\n## Date Range Boundaries\nUse inclusive lower and exclusive upper bounds, e.g. `date_range>=month_header` and `date_range<EDATE(month_header,1)`.\n
