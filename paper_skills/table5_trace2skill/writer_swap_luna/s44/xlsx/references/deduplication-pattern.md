# Deduplication Pattern\n\nWhen you need to combine rows that share the same values across multiple columns (e.g., merge rows with identical `A`, `B`, and `C` while summing column `D`), use a dictionary with a composite key.\n\n## Example\n\n```python\nimport openpyxl\nfrom collections import defaultdict\n\nwb = openpyxl.load_workbook('data.xlsx')\nws = wb.active\n\n# Read data into memory (skip header)\ndata = defaultdict(lambda: {'total': 0})\nfor row in ws.iter_rows(min_row=2, values_only=True):\n    key = (row[0], row[1], row[2])  # columns A, B, C\n    data[key]['total'] += row[3]    # sum column D\n\n# Write output starting at column G\nws.delete_cols(7, ws.max_column - 6)  # clear target area\nws.cell(row=1, column=7, value='Key A')\nws.cell(row=1, column=8, value='Key B')\nws.cell(row=1, column=9, value='Key C')\nws.cell(row=1, column=10, value='Total')\nrow_idx = 2\nfor key, val in data.items():\n    ws.cell(row=row_idx, column=7, value=key[0])\n    ws.cell(row=row_idx, column=8, value=key[1])\n    ws.cell(row=row_idx, column=9, value=key[2])\n    ws.cell(row=row_idx, column=10, value=val['total'])\n    row_idx += 1\n\nwb.save('data.xlsx')\n```\n\nAfter writing, run `recalc.py` if the workbook contains formulas that depend on the new data.
