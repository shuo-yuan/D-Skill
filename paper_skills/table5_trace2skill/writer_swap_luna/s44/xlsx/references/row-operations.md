# Row Operations\n\n## Deleting Rows by Condition\nWhen removing multiple rows that match a condition:\n1. Scan the range from the last row to the first (reverse order).\n2. Delete matching rows as you go.\nThis avoids row-index shifts that occur with top-to-bottom deletion.\n\nExample (pseudocode):\n```\nfor row in range(last_row, start_row, -1):\n    if cell_value(row, col) == target_value:\n        delete_row(row)\n```\n\n## Inserting Rows\nWhen inserting blank rows into a formatted worksheet, copy row height, hidden state, and cell styles from an adjacent source row. Process insertion targets in descending order to avoid shifting unprocessed rows.
