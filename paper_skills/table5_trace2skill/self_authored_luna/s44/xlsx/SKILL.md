## Core Workflow

1. Inspect the actual workbook before editing: identify sheet names and workbook order, dimensions, headers, populated bounds, blank separators, markers, formulas, styles, source and destination ranges, structural rows, and the exact output path. Do not rely on previews, active-sheet state, fixed positions, or assumed column letters.
2. Infer the requested transformation from workbook data and local examples. Map every target row or cell to its source before writing; apply all inclusion, exclusion, key, date, and relationship criteria together. Use in-memory aggregation or snapshots for grouping, deduplication, sorting, expansion, and row movement, and formulas for verified row-wise logic.
3. Make the smallest range-bounded change required. Preserve headers, repeated headers, totals, separators, formulas, styles, dimensions, hidden state, unrelated cells and sheets, and correct existing output unless replacement is explicitly required. Clear stale output only within the verified destination range.
4. Complete all value, formula, formatting, summary, insertion, deletion, and sheet changes before saving. Recalculate or materialize required formula results, save once to the exact requested path, reopen the file, and verify the complete affected range and representative boundary cases.

## Inspection

- Enumerate actual sheets, workbook positions, dimensions, populated cells, headers, first data rows, repeated headers, markers, formulas, helper columns, styles, number formats, protections, row heights, widths, criteria cells, and existing output layouts. Identify summary-boundary sheets explicitly and exclude the boundary and later sheets when required.
- Determine source and destination coordinates, data-row bounds, key and value columns, block boundaries, separators, structural TOTAL rows, and requested labels dynamically. Discover movable columns by exact header, record indexes before structural changes, and record marker rows rather than inferring boundaries from blanks.
- Distinguish None, empty strings, and whitespace-only values according to the task. Parse numeric text safely, normalize dates and recognized time suffixes, derive relative cutoffs from the maximum valid workbook date, and use inclusive or exclusive boundaries exactly as specified. Use literal matching only when required; otherwise use validated strings, casefolded substring or prefix tests, exact suffix checks, or component containment as appropriate.
- Use every specified identifying field for composite keys, duplicate detection, grouping, and lookups. For repeated keys, count or collect all matches in source order. For first-match searches, scan in the specified direction and stop at the first qualifying value. For two-dimensional lookups, identify both row selectors and period or column headers.
- Read original rows and relevant source cells into immutable records before inserting, deleting, expanding, sorting, or reordering. Preserve first-seen order where required, identify consecutive groups, distinguish authoritative IDs from target rows, and enumerate all candidate combinations for subset or tolerance-based selections. Convert data indexes to worksheet coordinates before editing.

## Writing Output

- Write complete aligned records, not independent columns. Emit qualifying rows contiguously in source order, flatten horizontal results in source and column order, preserve headers, and clear trailing or stale cells only within the requested range. For authoritative-ID synchronization, follow the authoritative order, reuse complete matching rows, and create blank placeholders for missing IDs.
- For grouping, deduplication, and enrichment, use the full composite key, aggregate designated fields once in memory, retain identifying fields and first-seen order, and use key-to-attributes maps. For expansion, snapshot originals, resolve invalid or non-positive counts to one, emit adjacent copies, and never iterate over a growing output.
- Preserve source order or apply the explicitly requested frequency, rank, or sort order using complete row records and typed values. Keep related columns together, regenerate derived positions after reordering, and use tie-breakers such as first appearance when specified. For wide-to-long or normalization tasks, retain identifiers and emit one row per selected variable.
- Build formulas systematically across the full target block with rebased destination references, anchored fixed ranges, relative copied references, explicit fallbacks, and correct condition precedence. Use `SUMIF` for one criterion, a `SUMPRODUCT`/`MATCH` membership mask for OR-list criteria, inclusive month starts with an exclusive `EDATE(month_header,1)` end, and `INDEX`/`MATCH` or equivalent matches for all required selectors. Use `IFERROR` or `IFNA` for unavailable lookups, and handle marker intervals from `previous_marker + 1` through `current_marker - 1`, including `=0` for consecutive markers.
- For conditional transfers, preserve the destination when the source is blank; for optional formulas, guard nonblank inputs and reference upstream cells rather than the target itself. Preserve structural TOTAL rows and recalculate totals from current detail rows. Delete worksheet rows from bottom to top after collecting original indexes, preserve required matching or protected rows, and copy neighboring properties when inserting blank rows.
- Copy values together with required styles, number formats, fonts, fills, borders, alignment, protection, row heights, and widths. Apply requested formatting only to explicitly affected populated cells. Preserve existing font attributes when changing a family, use exact requested formats, and do not let formatting changes coerce values. Save to the exact required path; if formulas cannot be recalculated, write verified static results when cached values are required.

## Verification

- Reopen the saved workbook at the exact output path and inspect the complete requested or graded range with formulas visible and evaluated values when applicable. Confirm the file exists, the intended sheet and positions were changed, and no writes occurred outside the requested bounds.
- Verify sheet order and summary boundaries, headers, row and column bounds, source-to-target mappings, authoritative-ID membership and order, placeholders, duplicate completeness, composite-key uniqueness, source order, filtered counts, date boundaries, lookup fallbacks, transposition order, and aligned related fields.
- Check formulas for correct sheet names, source endpoints, anchored and relative references, selector coverage, condition precedence, cumulative expansion, marker intervals, total ranges, and error handling. Recalculate with a capable engine when possible and verify cached or materialized results, including zeros, ties, non-winners, and tolerance-based totals.
- Confirm compact outputs, cleared stale rows, preserved separators and structural TOTAL rows, safe deletions and insertions, blank-source behavior, protected records, and unchanged unrelated content. For sorting or reordering, compare complete row tuples or row identifiers before and after and confirm the row multiset is preserved.
- Verify representative first, middle, transition, duplicate, gap-boundary, last, and final rows; all required populated destination cells; number formats; styles; protections; hidden state; row heights; column widths; and formatting scope. For labels or identifiers, check literals, separators, numbering, blank preservation, and suffix progression. Compare numeric totals using an appropriate tolerance rather than exact floating-point equality.

## Common Pitfalls

- Do not assume sheet names, active sheets, workbook order, dimensions, column positions, fixed ranges, block boundaries, marker offsets, data types, or summary limits. Do not edit before inspecting actual coordinates and local layout.
- Do not treat headers, repeated headers, totals, separators, whitespace-only cells, or protected records as ordinary data. Do not clear or rewrite outside the requested range, discard styles or dimensions, rebuild correct output unnecessarily, or overwrite the source when a separate output is required.
- Do not use incomplete keys, independent-column sorting, first-match logic when all duplicates are required, exact or case-sensitive matching when normalization is required, general substring checks for exact suffixes, fixed marker offsets, or current-date cutoffs for workbook-relative dates.
- Do not iterate over growing output, derive labels from generated cells, process row insertions or deletions top-to-bottom, delete on a marker alone, remove a required first match, propagate fills across blank boundaries, or leave stale formulas and summary rows. Do not use a pre-insertion index after columns shift.
- Do not copy formulas verbatim between rows, use unanchored cumulative or lookup ranges, omit selectors or fallbacks, assume formula text is calculated, or deliver uncached formulas where numeric results are required. Do not compare spreadsheet errors with the text `error`.
- Do not copy values without required formatting, apply formats to headers or unrelated cells, coerce values while formatting, use arbitrary oversized calculation ranges, ignore coefficient signs, or compare floating-point totals with exact equality. Always save, reopen, and verify the exact output file.
